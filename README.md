# 跨境物流异常叙述与索赔责任材料整理

本项目整理跨境物流索赔人员接收司机备注、承运商消息和收货方邮件。不同语言对“交接”“签收”和“暂存”的用法不一致，补充证据也可能推翻最初的事件顺序；若把一封邮件概括成最终责任结论，索赔窗口会对错过时限或错误承运环节作出判断。

演练资料位于 `data/claims.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
