# 跨境物流异常叙述与索赔责任材料整理

本项目整理跨境物流索赔人员接收司机备注、承运商消息和收货方邮件。不同语言对“交接”“签收”和“暂存”的用法不一致，补充证据也可能推翻最初的事件顺序；若把一封邮件概括成最终责任结论，索赔窗口会对错过时限或错误承运环节作出判断。

工具提供可复用的文本归档与案件整理能力：

- 按货件串起事件时间线，每段保留**作者、时间、地点、货件号、事件角色**
- 区分**观察 / 转述 / 推断 / 正式扫描记录**，收货方的猜测不会被写成已确认事实
- 补发或更正扫描到达后，被更正的事件保留可追溯记录，未提交的判断与时限提醒标为**需重核**
- 已提交的索赔资料**不可改写**，只能追加补证版本；报告显示采用的版本、材料哈希与后续变化
- 承运商重编号的旧号与新号需有**可核验的来源对应关系**才合并，相似字符串只提示、不合并
- 报告明确列出**仍需承运商确认的环节**与时限判断依据

项目只使用合成物流文本，**不自动判断法律责任或提交索赔**。

演练资料位于 `data/claims.json`（列表式）与 `data/scenario_handover.json`（分组式完整场景）。
项目环境使用 Python 3.11 标准库。

## 快速开始

```bash
python3 -m shipment_claims import data/scenario_handover.json --out archive.json
python3 -m shipment_claims report --archive archive.json --shipment SHP-2026-0417 --today 2026-11-22
```

完整用法、输入格式与设计约束见 [`docs/USAGE.md`](docs/USAGE.md)。
